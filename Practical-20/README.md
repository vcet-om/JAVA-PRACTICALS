# Practical-20 - File and Directory Operations Using Path, Files, and Java NIO API

## Aim
Performs modern non-blocking directory creation, file writing, reading, metadata inspection, and file deletion using java.nio.file.

## Files
- `NioDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac NioDemo.java

# Run
java NioDemo
```
