# Practical-11 - Multithreading Using Thread Class and Runnable Interface

## Aim
Creates concurrent threads by extending Thread class and implementing Runnable interface, synchronizing completion with join().

## Files
- `MultithreadingDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac MultithreadingDemo.java

# Run
java MultithreadingDemo
```
