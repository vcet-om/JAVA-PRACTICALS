# Practical-10 - Exception Handling (try, catch, finally, throw, throws, custom exceptions)

## Aim
Handles runtime exceptions using try-catch-finally, throws declaration, explicit throw statements, and custom checked exceptions.

## Files
- `ExceptionHandlingDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac ExceptionHandlingDemo.java

# Run
java ExceptionHandlingDemo
```

## Output
```text
Caught Standard Exception: / by zero
Finally block executed for arithmetic test.
Caught Custom Exception: Age 15 is not valid for voter registration.
Age 20 is valid for voting.
```
