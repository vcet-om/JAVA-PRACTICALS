# Practical-17 - Stream API (filter, map, sorted, and reduce)

## Aim
Processes data collections functionally using Stream pipeline operations: filter, map, sorted, and reduce.

## Files
- `StreamApiDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac StreamApiDemo.java

# Run
java StreamApiDemo
```

## Output
```text
Original Numbers: [5, 12, 8, 3, 19, 24, 7, 2]
Filtered (Even Numbers): [12, 8, 24, 2]
Mapped (Squares): [25, 144, 64, 9, 361, 576, 49, 4]
Sorted Numbers: [2, 3, 5, 7, 8, 12, 19, 24]
Reduced (Sum of elements): 80
```
