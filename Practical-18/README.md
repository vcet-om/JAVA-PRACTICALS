# Practical-18 - Java Date and Time API

## Aim
Demonstrates modern java.time classes: LocalDate, LocalTime, LocalDateTime, DateTimeFormatter, and Period.

## Files
- `DateTimeDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac DateTimeDemo.java

# Run
java DateTimeDemo
```
