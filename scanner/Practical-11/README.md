# Practical-11 (Scanner Edition) - Multithreading Using Thread and Runnable

## Aim
Implement multithreaded programs using the `Thread` class and the `Runnable` interface with user-specified iterations via `java.util.Scanner`.

## Files
- `MultithreadingDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac MultithreadingDemo.java
java MultithreadingDemo
```
