# Practical-18 (Scanner Edition) - Java Date and Time API

## Aim
Develop Java programs using the modern Date and Time API (`LocalDate`, `LocalTime`, `LocalDateTime`, `DateTimeFormatter`, `Period`) computing differences from user-supplied dates via `java.util.Scanner`.

## Files
- `DateTimeDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac DateTimeDemo.java
java DateTimeDemo
```
