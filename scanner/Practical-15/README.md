# Practical-15 (Scanner Edition) - Custom Annotation and Reflection

## Aim
Implement a custom annotation (`@PracticalInfo`) with runtime retention and extract its metadata dynamically using reflection along with user interaction via `java.util.Scanner`.

## Files
- `CustomAnnotationDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac CustomAnnotationDemo.java
java CustomAnnotationDemo
```
