# Practical-25 (Scanner Edition) - Mini Project: Student Record Management System

## Aim
Implement an interactive, menu-driven CLI Student Record Management System using Object-Oriented Programming (classes, encapsulation, array lists, dynamic search, delete, and formatted display) driven entirely by user input via `java.util.Scanner`.

## Files
- `StudentRecordApp.java`: Interactive Java program with menu system.

## External Project Reference
- GitHub Repository: [https://github.com/omspradippatil/Vadvan-management](https://github.com/omspradippatil/Vadvan-management)

## Compilation and Execution

```bash
javac StudentRecordApp.java
java StudentRecordApp
```
