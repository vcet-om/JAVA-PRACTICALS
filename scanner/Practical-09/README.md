# Practical-09 (Scanner Edition) - StringBuilder and Commonly Used String Methods

## Aim
Implement commonly used `String` methods and `StringBuilder` mutable methods using user input via `java.util.Scanner`.

## Files
- `StringDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac StringDemo.java
java StringDemo
```

## Sample Terminal Run
```text
=== String & StringBuilder Operations (User Input) ===
Enter a string (e.g., 'Hello Java World'): Hello Java World

--- String Class Methods ---
Original String: Hello Java World
Length: 16
Enter index to fetch character (0 to 15): 6

To Uppercase: HELLO JAVA WORLD
Enter a word to check if string contains it: Java
Contains 'Java': true
Enter target word to replace: World
Enter replacement word: Developers
Replaced Result: Hello Java Developers

--- StringBuilder Methods ---
Enter an initial string for StringBuilder (e.g. 'Programming'): Programming

Reversed: avaJ ni gnimmargorP
Restored back: Programming in Java
```
