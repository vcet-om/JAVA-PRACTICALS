# Practical-16 (Scanner Edition) - Lambda Expressions

## Aim
Develop Java programs to create lambda expressions with custom functional interfaces (`MathOperation`, `GreetingService`) using interactive user input via `java.util.Scanner`.

## Files
- `LambdaDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac LambdaDemo.java
java LambdaDemo
```

## Sample Terminal Run
```text
=== Lambda Expressions & Functional Interfaces (User Input) ===
Enter first number (a): 10
Enter second number (b): 5

--- Arithmetic Operations via Lambdas ---
10 + 5 = 15
10 - 5 = 5
10 * 5 = 50

Enter your name for personalized greeting lambda: Omkar
Hello, Omkar! Welcome to Java Lambda Expressions.
```
