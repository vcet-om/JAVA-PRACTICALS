# Practical-06 (Scanner Edition) - Inheritance, Method Overriding, and 'super' Keyword

## Aim
Develop Java programs demonstrating inheritance (`Manager extends Employee`), method overriding (`calculateSalary()`), and the `super` keyword using user input via `java.util.Scanner`.

## Files
- `InheritanceDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac InheritanceDemo.java
java InheritanceDemo
```
