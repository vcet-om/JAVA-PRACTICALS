# Practical-04 (Scanner Edition) - Classes, Objects, Constructors, Overloading, and 'this' Keyword

## Aim
Demonstrate object-oriented programming concepts including classes, objects, constructor overloading, and the `this` keyword using user input via `java.util.Scanner`.

## Files
- `StudentDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac StudentDemo.java
java StudentDemo
```
