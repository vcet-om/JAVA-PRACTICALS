# Practical-05 (Scanner Edition) - Method Overloading, Static Members, and Varargs

## Aim
Implement method overloading, static variables and methods, and variable-length arguments (`varargs`) using user input via `java.util.Scanner`.

## Files
- `MethodDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac MethodDemo.java
java MethodDemo
```

## Sample Terminal Run
```text
=== Method Overloading, Static Members & Varargs (User Input) ===
Enter two integers to add: 10 20
Result add(10, 20): 30

Enter two floating point numbers to add: 5.5 4.5
Result add(5.5, 4.5): 10.0

How many numbers do you want to pass to varargs sum()? 4
Enter 4 numbers:
1 2 3 4
Result of varargs sum(): 10

Total static method calls made: 3
```
