# Practical-03 (Scanner Edition) - 1D and 2D Array Sorting

## Aim
Implement sorting algorithms on user-provided one-dimensional (Selection Sort) and two-dimensional arrays (row-wise sort) via `java.util.Scanner`.

## Files
- `ArraySorting.java`: Interactive Java program.

## Compilation and Execution

```bash
javac ArraySorting.java
java ArraySorting
```
