# Practical-07 (Scanner Edition) - Abstraction Using Abstract Classes, Interfaces, and Default Methods

## Aim
Implement abstraction using an abstract class (`MotorVehicle`), interface (`Vehicle`), and default methods (`default void honk()`) using interactive user input via `java.util.Scanner`.

## Files
- `AbstractionDemo.java`: Interactive Java program.

## Compilation and Execution

```bash
javac AbstractionDemo.java
java AbstractionDemo
```

## Sample Terminal Run
```text
=== Abstraction, Interfaces & Default Methods (User Input) ===
Enter Electric Vehicle Brand/Model: Tata Nexon EV
Enter Battery Specifications (e.g. 40.5 kWh Lithium-ion): 40.5 kWh Lithium-ion

--- Testing Interface & Abstract Class Methods ---
Tata Nexon EV electric vehicle powered on silently.
Default Horn: Beep Beep!
Tata Nexon EV runs on 40.5 kWh Lithium-ion battery pack.
Tata Nexon EV electric vehicle powered off.
```
