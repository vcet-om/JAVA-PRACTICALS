# Practical-02 (Scanner Edition) - Decision-Making Statements, Loops, and Branching

## Aim
Develop Java programs using decision-making statements (`if-else`), loops (`for`, `while`), and branching statements (`break`, `continue`) to solve mathematical problems from user input.

## Files
- `MathProblems.java`: Interactive Java program.

## Compilation and Execution

```bash
javac MathProblems.java
java MathProblems
```

## Sample Terminal Run
```text
=== Mathematical Problems Solver (User Input) ===
Enter an integer: 7
7 is odd.
Factorial of 7: 5040
Is 7 a prime number? true
First 7 Fibonacci numbers: 0 1 1 2 3 5 8 
Enter upper limit to print odd numbers (skipping evens with continue): 10
Odd numbers up to 10: 1 3 5 7 9 
```
