# Practical-13 - Generic Classes and Generic Methods

## Aim
Defines generic class Box<T> and generic method printArray<E> to achieve type safety and code reusability.

## Files
- `GenericsDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac GenericsDemo.java

# Run
java GenericsDemo
```

```text
Box contains Integer: 1234
Box contains String: Generics in Java
Integer Array: 1 2 3 4 5
```
