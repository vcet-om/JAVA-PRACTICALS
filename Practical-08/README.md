# Practical-08 - Packages and Access Modifiers

## Aim
Demonstrates package creation, importing packages, and public, protected, default, and private access modifiers.

## Files
- `Main.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac mypack/Account.java Main.java

# Run
java Main
```
