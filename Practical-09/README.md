# Practical-09 - StringBuilder and Commonly Used String Methods

## Aim
Shows commonly used String methods (length, charAt, substring, toUpperCase, contains, replace) and mutable operations on StringBuilder (append, insert, reverse, delete).

## Files
- `StringDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac StringDemo.java

# Run
java StringDemo
```

## Output
```text
Original String: Hello Java World
Length: 16
Char at index 6: J
Substring (6, 10): Java
To Upper Case: HELLO JAVA WORLD
Contains 'Java': true
Replace 'World' with 'Developers': Hello Java Developers
After append: Programming in Java
After insert: Programming Core in Java
After reverse: avaJ ni eroC gnimmargorP
After delete: Programming in Java
```
