# Practical-12 - Pattern Matching Using Regular Expressions

## Aim
Uses Pattern and Matcher classes to validate email addresses and extract 10-digit phone numbers from text strings.

## Files
- `RegexDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac RegexDemo.java

# Run
java RegexDemo
```

## Output
```text
Email Validation Results:
student@vcet.edu.in -> Valid
john.doe@company.org -> Valid
invalid-email@ -> Invalid
user@domain..com -> Invalid

Extracted Phone Numbers:
Found phone number: 9876543210
Found phone number: 8765432109
```
