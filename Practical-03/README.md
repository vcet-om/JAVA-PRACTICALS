# Practical-03 - Sorting Using One-Dimensional and Two-Dimensional Arrays

## Aim
Performs selection sort on a 1D array and sorts each row of a 2D array matrix.

## Files
- `ArraySorting.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac ArraySorting.java

# Run
java ArraySorting
```

## Output
```text
Original 1D Array: 64 25 12 22 11 
Sorted 1D Array (Selection Sort): 11 12 22 25 64 
Original 2D Array:
9 2 7 
4 8 1 
5 6 3 
Row-wise Sorted 2D Array:
2 7 9 
1 4 8 
3 5 6
```
