# Practical-14 - Collections: ArrayList, LinkedList, Vector, and HashSet

## Aim
Demonstrates key Java Collections Framework structures: ArrayList, LinkedList, thread-safe Vector, and duplicate-eliminating HashSet.

## Files
- `CollectionsDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac CollectionsDemo.java

# Run
java CollectionsDemo
```

## Output
```text
ArrayList: [Java, Python, C++]
LinkedList: [Mango, Apple, Orange]
Vector: [10, 20, 30]
HashSet (duplicates removed): [Red, Blue, Green]
```
