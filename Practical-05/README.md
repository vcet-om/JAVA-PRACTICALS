# Practical-05 - Method Overloading, Static Members, and Variable-Length Arguments

## Aim
Demonstrates method overloading (different signatures and data types), static variables and methods, and variable-length arguments (varargs).

## Files
- `MethodDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac MethodDemo.java

# Run
java MethodDemo
```

## Output
```text
add(int, int): 30
add(double, double): 10.0
sum(1, 2, 3, 4): 10
sum(10, 20, 30): 60
Total method calls made: 4
```
