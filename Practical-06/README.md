# Practical-06 - Inheritance, Method Overriding, and super Keyword

## Aim
Demonstrates single inheritance, calling parent constructors and parent methods using the super keyword, and dynamic method overriding.

## Files
- `InheritanceDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac InheritanceDemo.java

# Run
java InheritanceDemo
```
