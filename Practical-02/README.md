# Practical-02 - Decision-Making Statements, Loops, and Branching Statements

## Aim
Implements mathematical problem solving (even/odd check, factorial calculation, prime check, and Fibonacci series) using if-else, for loops, while loops, and branching statements (break and continue).

## Files
- `MathProblems.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac MathProblems.java

# Run
java MathProblems
```

## Output
```text
Number: 7
7 is odd.
Factorial of 7: 5040
Is 7 prime? true
First 7 Fibonacci numbers: 0 1 1 2 3 5 8 
Odd numbers up to 10 (continue demo): 1 3 5 7 9
```
