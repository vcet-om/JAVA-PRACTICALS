# Practical-01 - Primitive Data Types, Variables, Type Conversion, and Type Casting

## Aim
Demonstrates Java's 8 primitive data types, variables, implicit type conversion (widening), and explicit type casting (narrowing).

## Files
- `DataTypesDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac DataTypesDemo.java

# Run
java DataTypesDemo
```

## Output
```text
Byte value: 10
Short value: 200
Integer value: 50000
Long value: 15000000000
Float value: 5.75
Double value: 19.99
Char value: A
Boolean value: true
Implicit Conversion (byte to int): 10
Implicit Conversion (int to double): 50000.0
Explicit Casting (double to int): 3
Explicit Casting (int 130 to byte): -126
```
