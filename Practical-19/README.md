# Practical-19 - File Handling Using Byte Streams, Character Streams, and Buffered Streams

## Aim
Performs file input/output operations using FileInputStream/FileOutputStream, FileReader/FileWriter, and BufferedReader/BufferedWriter.

## Files
- `FileHandlingDemo.java`: Source code implementation.

## Compilation and Execution

```bash
# Compile
javac FileHandlingDemo.java

# Run
java FileHandlingDemo
```

## Output
```text
Byte Stream Read: A B C D E 
Character Stream Read: Character Stream File Writing
Buffered Stream Read:
  Line 1: Buffered Stream Entry
  Line 2: High efficiency read write
```
